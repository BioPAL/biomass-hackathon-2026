# PolSAR and PolInSAR Analytics

**Challenge #1, Spectrum Pioneer: new analytics and feature detection**

## Goal

Bring BIOMASS P-band observations to life: process BIOMASS data in [PyPolSARpro](https://polsarpro.readthedocs.io/) and use the resulting data layers for feature detection in a selected application, for example flooding under the forest canopy, ice structures, or hidden desert features (archaeology). Contribute custom visualisation routines back to open source.

## Roadmap

- **Foundation**: ingest BIOMASS data with PyPolSARpro and extract descriptive polarimetric parameters. Design and implement custom RGB visualisations optimised for specific geographic signatures. Package, test, and submit the code as a pull request to PyPolSARpro.
- **Deep dive**: investigate how temporal changes affect the features (for example flooding in forests), and how these changes can be identified in space and time.

## Data sources

- BIOMASS core mission products
- PyPolSARpro framework: https://polsarpro.readthedocs.io/
- Example sites to be provided by the topic referent before the hackathon.
