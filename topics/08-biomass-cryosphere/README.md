# BIOMASS for Cryosphere

**Challenge #8, Ice Sentinel: cryosphere structural inversion framework**

## Goal

Exploit long-wavelength penetration to map internal ice structure. Implement Jupyter notebooks to support the analysis of BIOMASS data for ice applications: ice structure, ice velocity (ice flow), and sea ice concentration (sea ice thickness as a possible addition).

## Roadmap

- **Foundation**: a notebook configured to dissect ice structures, map ice velocity, and compute localised sea-ice concentration maps.
- **Deep dive**: identify, evaluate, and test polarimetric decompositions that maximise structure mapping, and run a comparative study of BIOMASS performance against concurrent NISAR products.

## Data sources

- BIOMASS core mission products
- NISAR products, availability over the same areas to be checked
