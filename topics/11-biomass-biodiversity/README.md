# BIOMASS for biodiversity

**Challenge #11, Eco-Architect: vertical profiling for ecosystem biodiversity**

## Goal

Evaluate vertical and horizontal forest structure to support biodiversity mapping. Implement a tomographic processor in a Jupyter notebook, based on the example code from the PolInSAR course, or the processed tomocubes from Lope as a backup.

## Roadmap

- **Foundation**: a tomographic processor that resolves high-resolution vertical and horizontal reflectivity profiles, plus a classification tool deriving horizontal and vertical profile classes.
- **Deep dive**: an intelligent classifier or machine learning model that sorts canopy profiles into structural diversity categories, validated against ground forest class maps.

## Data sources

- BIOMASS core mission products
- Forest class maps for validation, still to source
