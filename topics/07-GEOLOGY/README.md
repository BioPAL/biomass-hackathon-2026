# BIOMASS for Geology

**Challenge #7, Subterranean Secrets: P-band radar for paleoclimatological geology**

## Goal

P-band penetrates dry desert sand. Implement a Jupyter notebook to extract BIOMASS images and suggest polarimetric parameters or stack-based processing that can identify paleoclimatological structures such as fossilised river networks and buried channels.

## Roadmap

- **Foundation**: a notebook pipeline that extracts polarimetric descriptors optimised for identifying paleo-channels.
- **Deep dive**: interferometric routines to estimate the depth of the buried river channels.

## Data sources

- BIOMASS core mission products
- SaharaSAR L-band data: https://saharasar.astrophy.u-bordeaux.fr/saharaCesium.php (to confirm)
