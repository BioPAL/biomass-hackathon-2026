# 3D forest structure visualisation

**Challenge #4, X-Ray the Forest: 3D tomographic canopy visualiser**

## Goal

Turn BIOMASS tomographic data into interactive 3D views of forest structure. Implement a tomographic processor in a Jupyter notebook, based on the example code from the PolInSAR course. If that is not ready in time, use the processed tomocubes from Lope as a backup.

## Roadmap

- **Foundation**: a working tomographic processor in a notebook (PolSAR framework) to build a radar intensity cube, or load the backup Lope tomocubes.
- **Deep dive**: ingest TLS Quantitative Structure Models (QSMs) and combine them with ALS forest height metrics into one 3D visualisation relating canopy height to the radar-derived internal forest density.

## Data sources

- BIOMASS core mission products
- Gabon, Lope: ALS and TLS
- Ghana, Ankasa: TLS
- Colombia, Amacayacu: ALS
- Brazil sites: SFB ALS acquisitions, available on MAAP
