# RFI removal

**Challenge #2, Signal Guardian: advanced Radio Frequency Interference (RFI) mitigation**

## Goal

P-band operates in a crowded radio spectrum. Investigate novel techniques to detect and remove residual Radio Frequency Interference from BIOMASS SAR imagery, and develop a tool to identify residual RFI and correct it.

## Roadmap

- **Foundation**: investigate novel signal processing algorithms and write a script that detects RFI patterns within the radar data.
- **Deep dive**: package the algorithms into an end-user tool or notebook for automated anomaly detection and interactive RFI correction.

## Data sources

- BIOMASS core mission products
- Example data to be provided by the topic referent before the hackathon.
