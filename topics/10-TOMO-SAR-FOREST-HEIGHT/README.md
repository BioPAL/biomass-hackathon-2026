# Forest Height from TomoSAR

**Challenge #12, Canopy Tracker: TomoSAR forest height and terrain modeler**

## Goal

Separate the forest from the floor. Implement a tomographic processor in a Jupyter notebook, based on the example code from the PolInSAR course, or the processed tomocubes from Lope as a backup, and a method that traces the top of the canopy and the ground layer. Validate against ALS data.

## Roadmap

- **Foundation**: a tomographic processor plus a geometric tracing algorithm that automatically extracts the top-of-canopy profile and the underlying ground layer, validated against airborne ALS elevation models.
- **Deep dive**: compare against forest height products such as the Meta forest height map, and GEDI height and ground estimates.

## Data sources

- BIOMASS core mission products
- Brazilian ALS high-accuracy lidar datasets (SFB, on MAAP)
- Meta forest height map and GEDI, for the comparison
